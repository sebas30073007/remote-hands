La interfaz de operación es una aplicación Unity para **Meta Quest 3**.
Desde ella, el operador ve el entorno del robot en realidad mixta
—passthrough—, conduce la base móvil, maneja el manipulador y cambia los
modos de percepción.

Todos los controles viven en un canvas world-space que flota frente al
operador.

La asimetría es deliberada y conviene entenderla antes de empezar: **el
protocolo está completo, la aplicación no**. Con lo publicado aquí se puede
escribir un cliente propio —en Unity, en Unreal o en un escritorio— que hable
con el robot exactamente igual que este. Lo que no se puede es recompilar
esta app concreta.
