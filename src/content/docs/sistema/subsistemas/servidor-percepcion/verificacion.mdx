La verificación de este subsistema comprueba dos cosas: que cada canal de
datos publica a la frecuencia esperada, y que el enlace WiFi entre el robot
y la NUC se mantiene estable durante una sesión de trabajo.

## Pruebas pendientes

Las siguientes pruebas quedaron documentadas en el proyecto original sin
ejecutarse:

| Prueba | Estado |
| --- | --- |
| Telemetría de encoders de tracción (10–20 Hz) | Pendiente de integración |
| Latencia de red local y extremo a extremo (XR → robot → XR) | Pendiente de medir |
| SLAM: generación de mapa en pasillo estructurado | Pendiente |
| Watchdog: el robot se detiene al perder conexión | Pendiente |
| Stream RGB-D completo al headset XR | Pendiente |

Conviene no confundir la segunda con el [experimento de latencia
WiFi](/latencia-wifi/#resultados) que
sí está ejecutado. Aquel mide el protocolo entre la interfaz MR y un nodo
edge simulado. La prueba pendiente mide el lazo físico completo, con el
robot real dentro.
