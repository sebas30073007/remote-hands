Ninguno se copió todavía a este repositorio. Mover 77 MB de video a un repo
Git es una decisión con consecuencias —Git LFS, hosting externo, o
aceptarlo tal cual— y sigue pendiente. Cuando se resuelva, cada archivo debe quedar
enlazado como `evidence` en su `VerificationResult` correspondiente.
