El gripper es la pinza en el extremo del manipulador. Abre y cierra sus dos
dedos a la posición en milímetros que pide el operador, y se detiene solo si
algo le impide seguir.

## Sinopsis

### Qué es

Dos pinzas impresas en 3D con mecanismo de **piñón y cremallera**, movidas
por un motor con encoder y reductor. Lo controla un **ESP32-C3 SuperMini**
con un driver de motor **TB6612FNG**. A diferencia de las otras dos placas
del robot, este controlador **no tiene PCB dedicada**: va cableado a mano.

### Cómo funciona

El piñón central engrana con las cremalleras internas de ambas pinzas, que
se desplazan en sentidos opuestos: abren o cierran de forma sincronizada.

El firmware convierte la posición pedida en cuentas del encoder y lleva el
motor hasta ella con un perfil de velocidad suave. El encoder es la única
retroalimentación de posición: si deja de cambiar durante 500 ms con el motor
activo, el firmware asume un obstáculo y detiene el motor.

### Encoder de cuadratura

El firmware decodifica el encoder por interrupciones, con una tabla de
transición *phase-correct* que da resolución de ±1 count. La lectura del
contador es atómica: se envuelve en `disable_irq`/`enable_irq` para que la
interrupción no la modifique a media lectura.

### Control de posición

```text
1. mm_to_count(mm) — convierte mm a counts de encoder
2. Si |target − current| ≤ 35 counts: ya está en posición, freno + stop
3. Bucle de control cada 8 ms: perfil de velocidad con boost inicial
   de 12 ms, 30 % de recorrido en aceleración, 55 % en desaceleración
4. Detección de stall: si el encoder no cambió en 500 ms, detiene con
   freno activo y guarda la posición del evento
```

El perfil de velocidad usa la función `smoothstep01(x) = x²(3 − 2x)` para
suavizar las transiciones. Sin ella, los escalones de aceleración provocan
saltos mecánicos en el mecanismo de piñón y cremallera.

### Comandos USB serie

Ninguno bloquea: el firmware sigue atendiendo el puerto mientras el motor se
mueve.

| Comando | Descripción |
| --- | --- |
| `m <mm>` | Ir a posición absoluta |
| `o <mm>` / `c <mm>` | Abrir / cerrar delta mm desde la posición actual |
| `to` / `tc` | Ir a completamente abierto / cerrado |
| `s` / `b` | Stop suave / freno activo inmediato |
| `sc` / `so` | Guardar posición actual como cerrado / abierto |
| `save` / `load` | Guardar / cargar calibración desde JSON |

Publica una línea de estado cada 250 ms y tras cada comando:

```text
GRIPPER_STATE mm=40.000 count=-14285 target_mm=40.000 target_count=-14285 busy=0 calibrated=1 open_count=-28570 closed_count=0
```

### Calibración

1. Mover manualmente (o con pulsos `po`/`pc`) a la posición abierta máxima
   → `so` guarda `OPEN_COUNT`.
2. Mover a la posición cerrada máxima → `sc` guarda `CLOSED_COUNT`.

Los valores se guardan en `gripper_state.json` con escritura atómica
(archivo temporal + rename), para que un corte a media escritura no
corrompa el archivo. Si no existe o está corrupto, el gripper arranca sin
calibrar y bloquea los comandos de posición hasta recalibrar.

La calibración del gripper construido sirve de referencia de orden de
magnitud, pero **no se puede copiar**: depende del montaje de cada
mecanismo.

```json
{ "closed_count": 0, "open_count": -28570 }
```

El signo negativo es la convención de sentido del encoder: abrir cuenta hacia
abajo desde el cero de cerrado. De ahí sale la resolución de 357,1 counts/mm.

### Prueba desde tu PC

El script hace lo mismo que la NUC por COM5: pide el estado con `p` y manda
posiciones con `m <mm>`, esperando a que cada movimiento termine.

1. Conecta el USB-C del ESP32-C3 a la PC y busca su puerto COM.
2. Instala la dependencia: `pip install pyserial`.
3. Corre la prueba:

```bash
python prueba_gripper.py --puerto COM5
python prueba_gripper.py --puerto COM5 --mover --posiciones 60 20 40
python prueba_gripper.py --puerto COM5 --consola
```

<Artifact href="/software/pruebas/prueba_gripper.py" name="Prueba del gripper — prueba_gripper.py" />

La primera línea muestra la posición, `busy` y `calibrado`. Si no está
calibrado, los comandos de posición están bloqueados: calibra primero con
`so` y `sc` desde `--consola`.
