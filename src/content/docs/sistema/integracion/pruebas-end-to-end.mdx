**Página reservada.** Estas pruebas verificarían el lazo completo, desde que
el operador da una orden en la interfaz XR hasta que el robot la ejecuta
físicamente.

Varias páginas de subsistema marcan hoy esa integración como «en proceso» o
«pendiente». Esta página consolidará los resultados cuando existan, con el
mismo formato de `VerificationResult` que ya usan las verificaciones por
subsistema.

El procedimiento se queda sin escribir a propósito. La fotografía de
arriba documenta lo que sí existe —el resultado físico, que se construyó y
funciona—, pero rellenar el texto con generalidades daría la impresión de
que el proceso está resuelto como algo repetible, y no lo está.
