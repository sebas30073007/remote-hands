El proyecto original no llevaba un esquema de versionado formal, ni para
hardware ni para software. Esta página describe por tanto el **estado real
verificado** de cada pieza, no una release numerada: asignar un número de
versión que nadie definió sería inventar información.

Adoptar un esquema de versionado hacia adelante es una decisión pendiente.

## Próximo hito

Todavía sin definir. El propio proyecto original dejó cuatro candidatos
anotados en `11-pendientes.md`:

- PCB dedicada para el gripper, que reemplace el montaje actual en
  protoboard.
- Modelo cinemático del robot móvil, para odometría y trayectorias
  programadas.
- Cinemática inversa del manipulador.
- Captura de los encoders de tracción, para cerrar el lazo de control de
  velocidad.
